Privacy

Last updated: September 28, 2026

Speed Test By Rahul is designed to run primarily in your browser. The site's test history is stored in your browser's local storage and is not presented as a server-side account or cloud history.

When you run a speed test, your browser communicates with Cloudflare's speed-test infrastructure to perform download, upload and latency measurements. Cloudflare's handling of network requests is governed by Cloudflare's own policies and terms.

The site may display network metadata returned by the test service, such as IP address, network/ASN information and approximate location when available. This information is used to display test details in the page; the current site does not create a user account for it.

Do not use the test if you are not comfortable sending test traffic to the third-party speed-test infrastructure described above.
