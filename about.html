About Speed Test By Rahul

Speed Test By Rahul is a browser-based tool for measuring download speed, upload speed, ping and jitter.

The current implementation sends test traffic to Cloudflare's public speed-test endpoints. Results are measurements from the browser's connection to the selected/nearest available edge and can differ from speeds reported by an ISP, router, or dedicated test service.

  • No app installation is required.
  • Test history is stored locally in the browser.
  • The page does not claim raw ICMP ping; its latency measurement is HTTP round-trip time.
  • Unsupported browser/network information is shown as unavailable rather than guessed.
