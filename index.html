How this works — this page runs as one file with no server of its own. Download, upload, ping and jitter are measured for real using fetch / XMLHttpRequest against Cloudflare's public network, timed with performance.now() — nothing is randomly generated. "Ping" measures HTTP round-trip time, not raw ICMP ping. If a measurement can't complete — offline, a firewall, a blocked cross-origin request — it's shown honestly as Unavailable rather than guessed.

Results are a real-world approximation based on a single connection to Cloudflare's nearest edge location, not a substitute for dedicated ISP-grade testing tools. Actual speeds vary with network conditions, device and Wi-Fi signal.

Privacy: nothing is sent to any server run by this page. Test history lives only in your browser's local storage and is never uploaded anywhere — use Clear to remove it.
